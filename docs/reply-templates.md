# Reply templates

Starting points, not scripts. Each one is written plainly on purpose. Fill the brackets with real facts, then run every draft through the [60-second pass](emails.html#3-the-60-second-pass) before sending — especially the fact check.

**Before sending, always:**
1. Facts verified: dates, amounts, order numbers, links, names.
2. Sounds like you? Read it aloud once.
3. No promise you can't keep this week.

## Reader email questions

```
Hi [Name],

Thanks for the question about [topic]. Short answer: [one-sentence truth].

Longer answer: [2–3 sentences of actual facts you supply].

If that doesn't fully cover it, reply and I'll go deeper — no FAQ robots here, just me.

[Your name]
```

## "Can I get a discount?"

```
Hi [Name],

Thanks for asking! I keep pricing simple: [what you offer is priced X and stays X].

What I *do* have: [free version / sample chapter / newsletter, whatever is true]. It's the best way to see if it's for you before buying: [link].

Thanks again,
[Your name]
```

## Refund / return request (accepted)

```
Hi [Name],

Sorry this didn't work out — that request is no trouble. I've issued the refund for [amount] to [original payment method]; you should see it within [realistic timeframe, verified by you].

No need to return anything [or: mail back by [date]], and feel free to tell me what missed the mark. Genuinely useful.

Thanks for giving it a try,
[Your name]
```

## Refund / return request (declining, with reason)

```
Hi [Name],

Thanks for reaching out. This one's outside my return window [state your actual policy, stated plainly and up front on your site too], so I can't issue a refund here.

What I can do: [a real alternative — swap to another title, check a technical issue, point to a resource].

Sorry about the friction,
[Your name]
```

## "You're wrong about X" / disagreement

```
Hi [Name],

I appreciate you taking the time to push back. Here's what I can tell you: [your reasoning, your evidence — supplied by you, never invented].

And you might be right about [the steel-manned part of their point]. I'll [what you'll actually do: revisit the chapter, test it, or clearly state you stand by it].

Thanks for reading closely,
[Your name]
```

## Late delivery / you messed up

```
Hi [Name],

I owe you an update and an apology: [what happened, in one honest sentence — no blame, no excuses].

Where it stands now: [current state]. What happens next: [the fix, with a date].

You'll hear from me by [date] either way.

[Your name]
```

## Media / collab / "can you speak at..."

```
Hi [Name],

Thanks for thinking of me! This one sounds like [describe it back accurately — goes double if AI summarized it].

Two quick checks from my side before I confirm: [your constraints — time, scope, what's in it for both sides].

If it all fits, count me in.

[Your name]
```

## Declining eligible-but-not-right requests

```
Hi [Name],

Thanks for the offer — it's just not the right fit for me right now, and I'd rather tell you straight than slow-walk it.

For this round: [name the real reason in one clause if it helps: "my plate is full through [month]," "outside what I write about"].

If [family-friendly future condition, e.g. "something in [adjacent topic] comes up"], my answer might be different. Good luck with it!

[Your name]
```

## Using AI with these

The fast path: paste the matching template into your prompt like this —

```
Here's my reply template:
[paste template]
Here's the situation:
[facts only, names removed]
Draft the filled-in version, keeping my wording as much as possible.
```

Then still do the 60-second pass. AI is excellent at slotting in facts; it's bad at knowing whether the *situation* fits the template. If the message feels squeezed, it is — write it fresh instead.

## What these deliberately avoid

- Phrases management consultants use to sound busy: *"touching base," "circling back," "per my last email."*
- Fake enthusiasm; emojis are fine if you use them, but nothing here requires them.
- Apologizing more than once per email.
